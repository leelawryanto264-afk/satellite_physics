# satellite_physics

This is a browser based simulation that is designed to model and visualize satellite trajectories by changing variables and time parameters.

## AI usage:

- Created an outline of all mathematical concepts to make the satellite simulation
- How to format the physics formulas into streamlit
- Fix syntax errors & explained linear algebra concepts

## Tech Stack

- Streamlit - deploys website for free in Streamlit Community Cloud
- Numpy - compiles data into matrix grids for the RK4 algorithm to work
- Math - calculates basic trignometry, converting degrees into radians, and squaring numbers
- Matplotlib - uses data from numpy to create a chart that shows satellite trajectories and velocity timeline

## Features

- 2D and 3D Toggle
- Explains the physics formulas used
- User can change altitude, speed, inclination angle, and time parameters
- Shows satellite location at specific point in time (hours)
- On/off grid and numbers for better viewing
